## ✦ A little about me

Hello! I'm **Khadija Bensaad**, a third-year engineering student @ **ISI Tunis**, specializing in **Communication Infrastructure Development**, after earning my Bachelor's degree in Computer Science from ESSTHS, Sousse.

I'm passionate about exploring the intersection of **Artificial Intelligence, Software Engineering, and Computer Infrastructure**.

I love understanding how things work behind the scenes, transforming ideas into intelligent applications, and exploring technologies that can solve real-world problems.

- 🤖 **Artificial Intelligence:** Machine Learning, Deep Learning, Computer Vision, LLMs and Explainable AI.
- 🛡️ **AI Security:** Exploring LLM security, prompt injection, RAG vulnerabilities and intelligent agents.
- 💻 **Software Engineering:** Full-stack development, APIs, mobile applications and system design.
- 🌐 **Computer Infrastructure:** Computer networks, networking protocols, Linux, DevOps and cloud technologies.
- ✨ **Beyond technology:** Leadership, volunteering, intercultural exchange and continuous learning.
